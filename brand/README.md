# Marca — My Packs Pro

Direção **Pilha**: três camadas empilhadas, cada uma com a aresta tingida por uma
cor de rótulo do Premiere. Diz "packs organizados" sem usar ícone de pasta, e a
aresta colorida é literalmente a função de rótulo que o plugin escreve no projeto.

## Arquivos

| Arquivo | Uso |
|---|---|
| `mark.svg` | Marca principal, fundo transparente |
| `mark-on-dark.svg` | Com fundo escuro arredondado — favicon, avatar |
| `mark-mono-light.svg` | Uma cor, para fundos escuros |
| `mark-mono-dark.svg` | Uma cor, para fundos claros |
| `lockup.svg` | Marca + nome, horizontal |
| `icon-*.png` | Rasterizados: 23, 48, 96, 256 px |
| `panel-icon-*.png` | Ícone do menu do Premiere |

## Por que o ícone do painel é diferente

O menu do Premiere é escuro, e as duas camadas superiores da marca
(`#2A3240` e `#3A4454`) somem contra ele. A variante do painel usa tons claros
e a aresta mais larga, porque a 23 px um traço de 5 unidades desaparece.

## Cores

| | Hex | Uso |
|---|---|---|
| Fundo | `#101318` | Base escura |
| Superfície | `#171B22` | Cartões, painéis |
| Texto | `#E9ECF1` | Primário |
| Secundário | `#99A1AE` | Apoio |
| **Acento** | **`#F5A524`** | Ações, destaques |

O acento é âmbar de propósito: o Premiere é azul e violeta por toda parte, e uma
cor quente separa a marca da interface em que ela vive em vez de se dissolver
nela. O cinza puxa levemente para o azul — assenta no escuro do Premiere sem
parecer sujo.
